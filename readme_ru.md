# NoABS.Eagle3D (No Autodesk BS Eagle3D )

NoABS.Eagle3D это локальное и быстрое средство 3D визуалицазии печатных плат для EagleCAD.
NoABS.Eagle3D состоит из нескольких скриптов, реализующих экспорт платы в 3D (как для предпросмотра c текстурами, так и в формате step для импорта в mCAD) и утилиты glue, предназначенной для сопоставления 3д моделей футпринтам из eagle библиотек 

## Склеивание моделей и библиотек.

Это процедура осуществляется утилитой glue. Процедура "приклеивания" 3D модели к библиотеке заключается в записи в файл библиотеки в тег description футпринтов небольшого количества метаданных для корректной ориентации модели компонента на футпринте. Это никак не влияет на работу самой библиотеки в Eagle. Все файлы моделей компонентов должны храниться в папке step в директории утилиты glue. При этом имена step-моделей должны совпадать с именами футпринтов в библиотеке. Футпринт с "приклеенной" к нему моделью можно копировать из библиотеки в библиотеку, при этом связь между футпринтом и моделью сохраняется.

## Библиотека референсных футпринтов

Хотя в составе NoABS.Eagle3D и нет никаких библиотек, можно воспользоваться репозиторием [NoABS.Libs](https://github.com/j3qq4hch/NoABS.Libs), который содержит набор небольшой набор библиотек компонентов Eagle, к части футпринтов которых уже приклеены 3D модели. В этом репозитории есть так называемая библиотека референсных футпринтов `reference_packages_3d.lbr`. В ней содержатся эстетически привлекательные и технологически корректные футпринты разных компонентов с приклеенными к ним 3D моделями, которые также были отобраны вручную. 

## Сценарий использования 

Идея заключается в том, что в библиотеки пользователя нужно скопировать футпринты из референсной библиотеки, которые перезапишут футпринты пользователя референсными (о которых известно, что они хороши) с приклеенными к ним моделями.

Впрочем, пользователю ничего не запрещает модифицировать и сами референсные футпринты, и приклеивать модели к своим библиотекам напрямую при помощи утилыт glue. Референсная библиотека ничего не навязывает, только предлагает небольшое удобство.

## Автоматическое распространение изменений

Т.к. обычно существует более одной библиотеки, которые используют одни и те же футпринты, удобно иметь возможность скопировать референсный футпринт сразу во все такие библиотеки. Для этого есть скрипт downstream.py, который берет список всех футпринтов из референсной библиотеки и копирует заменяет все совпадающие футпринты во всех библиотеках в указанной директории.
Этот же функционал встроен и в утилиту glue.

Подробнее про использование можно прочитать в [инструкции по применению](USAGE_RU.md)
