# NoABS.Eagle3D — Инструкция по использованию

NoABS.Eagle3D превращает `.brd` Eagle в 3D-модель — либо **GLB** (лёгкая, текстурированная,
для предпросмотра в любом glTF-просмотрщике), либо **STEP** (точная B-rep сборка для MCAD:
FreeCAD, Fusion 360, SolidWorks, Siemens NX…). Всё работает локально.

Управление — из одного ULP `export3D.ulp` внутри Eagle. GLB и STEP — это два представления
одной платы, выбирай нужное.

---

## Разовая настройка: `noabs.ini`

Две вещи относятся к рабочему месту, а не к плате, поэтому настраиваются один раз.
`noabs.ini` лежит рядом с `eagle2gltf` / `eagle2step` и хранит пути к библиотекам моделей:

```ini
# Путь к библиотеке GLB-моделей компонентов (для экспорта GLB)
components_dir=C:/path/to/glb_models

# Путь к библиотеке STEP-моделей компонентов (для экспорта STEP)
step_components_dir=C:/path/to/step_models
```

Имена файлов должны совпадать с именами **футпринтов** Eagle (регистр не важен): футпринт
`SOIC8` → `SOIC8.glb` / `SOIC8.step`. Компоненты без подходящей модели просто пропускаются.

## Запуск из Eagle

Скрипт запускается командой `RUN export3D.ulp` в командной строке. Режимы:

| Команда | Что делает |
|---|---|
| `RUN export3D.ulp` | Первый раз (плата ещё не настроена): показывает **диалог настроек**, сохраняет их и останавливается. Запусти ещё раз, чтобы сгенерировать **GLB**. |
| `RUN export3D.ulp STEP` | Сгенерировать **STEP** (плата + компоненты) вместо GLB. |
| `RUN export3D.ulp SET` | Открыть диалог настроек заново (без генерации). |
| `RUN export3D.ulp OPEN` | Открыть уже сгенерированный GLB в системном просмотрщике. |
| `RUN export3D.ulp LOG` | Открыть лог последней генерации (есть только при включённом «Leave artifacts»). |

Результат (`<плата>.glb` или `<плата>.step`) появляется рядом с `.brd`. По умолчанию
никакого мусора не остаётся.

> **Первый запуск только сохраняет настройки — модель не генерируется.** Запусти скрипт
> второй раз (без аргументов), чтобы сгенерировать. Диалог об этом напоминает.

### Почему второй клик / почему иногда не мгновенно

В Eagle 9 есть баг рендеринга слоёв при экспорте текстур, поэтому для GLB этап текстур
автоматически выполняется в **поставляемом headless Eagle 7** (ставить или трогать его не
нужно — он идёт в комплекте). Может мелькнуть окошко — это нормально. STEP текстуры не
нужны, это чистая геометрия, поэтому Eagle 7 для него не задействуется.

## Настройки (диалог)

Настройки хранятся как **глобальные атрибуты внутри платы** (`NOABS_*`). Они
человекочитаемы (прямо в свойствах платы видно «solder mask = Blue») и располагаются внутри файла `.brd`.

| Настройка | Смысл |
|---|---|
| **Solder mask** | Цвет платы: Green / Blue / Red / Black / Purple / White |
| **Pad finish** | ENIG (золото) или HASL (олово) |
| **Silkscreen** | Белая или чёрная шелкография |
| **Texture DPI** | Разрешение текстуры для GLB (зажато 72–2400; 400–600 — хороший баланс) |
| **Min Priority3d** | Фильтр компонентов — см. ниже |
| **Photorealistic vias** | Рисовать отверстия via тёмными точками в текстуре |
| **Merge components by material** | Только GLB: объединять непомеченные компоненты по материалу, чтобы крупные платы не тормозили в веб-просмотрщиках (ценой потери структуры). Для STEP игнорируется. |
| **Leave 3D model generation artifacts** | Оставлять промежуточные текстуры/логи в `NoABS_tmp` для отладки (по умолчанию выкл — без мусора) |

Цвет платы в STEP тоже берётся из настройки **Solder mask**.

## Какие компоненты попадают в модель: `priority3d`

`priority3d` — атрибут на конкретном компоненте (Edit → Attributes на детали или в
библиотеке). Работает в связке с настройкой **Min Priority3d**:

- **Не задан / `0`** — обычное поведение: компонент включается.
- **`Min Priority3d` = N (N > 0)** — включаются **только** компоненты с `priority3d ≥ N`.
  Так можно облегчить тяжёлую плату до механически важных деталей (разъёмы, крупные
  модули): проставь им высокий `priority3d`, подними порог — и всё остальное отвалится.
  Удобно для быстрых лёгких MCAD-моделей.
- **`priority3d` = `-1`** (любое отрицательное) — **никогда** не ставить деталь в 3D,
  независимо от порога. Это для обратного случая: «нужно всё, кроме вот этих нескольких».

> Если компонент загадочно пропал — проверь его атрибут `priority3d`: забытый `-1` —
> обычная причина. Атрибут живёт на самой детали, там и смотри.

## Метаданные позиционирования компонентов

Чтобы модель села на оказалась расположена на футпринте корректно (нужная высота, поворот, смещение), в
`description` футпринта должны быть метаданные в формате `<!--3d:{...}-->` (смещение
X/Y/Z и углы поворота). Без них модель ставится в ноль футпринта без поправок — для
большинства корпусов это неверно.

Метаданные создаются утилитой **glue** из этого пакета, которая позволяет визуально разместить модель и записать метаданные в `description` футпринта. Эта связь сохраняется с футпринтом при копировании
между библиотеками.

## Утилиты командной строки (продвинутое / отдельно)

ULP вызывает их за тебя, но можно запускать и напрямую. Путь к библиотеке обе берут из
`noabs.ini`, если не передан `-c`.

### eagle2gltf — GLB

```
eagle2gltf.exe board.brd
eagle2gltf.exe board.brd -o out.glb
eagle2gltf.exe board.brd -c path\to\glb_models\ --min-priority 2 --merge
```

| Аргумент | Описание |
|---|---|
| `board.brd` | Файл платы Eagle (обязательный) |
| `-o`, `--output` | Выходной `.glb` (по умолчанию рядом с BRD) |
| `-t`, `--thickness` | Толщина платы в мм (по умолчанию из BRD) |
| `-c`, `--components` | Папка GLB-моделей (переопределяет `noabs.ini`) |
| `--min-priority` | Минимальный `priority3d` для включения (по умолчанию 0) |
| `--merge` | Объединять непомеченные компоненты по материалу |
| `--textures` | Папка PNG/BMP-текстур (по умолчанию авто) |
| `--leave-artifacts` | Оставлять промежуточные текстуры/GLB |
| `--open` | Открыть результат после генерации |
| `--log` | Путь к лог-файлу |

### eagle2step — STEP

```
eagle2step.exe board.brd
eagle2step.exe board.brd -o out.step
eagle2step.exe board.brd -c path\to\step_models\ --min-priority 2
```

| Аргумент | Описание |
|---|---|
| `board.brd` | Файл платы Eagle (обязательный) |
| `-o`, `--output` | Выходной `.step` (по умолчанию `<плата>.step`) |
| `-t`, `--thickness` | Толщина платы в мм (по умолчанию из BRD) |
| `-c`, `--step-dir` | Папка STEP-моделей (переопределяет `noabs.ini`) |
| `-a`, `--assembly-output` | Путь сборки (по умолчанию как `-o`) |
| `--min-priority` | Минимальный `priority3d` для включения (по умолчанию 0) |
| `--leave-artifacts` | Оставлять промежуточную плату-без-компонентов |
| `--debug` | Сохранить TCL/BAT вместо запуска DRAWEXE |

Результат — **один** файл `<плата>.step` = плата + компоненты, корректное дерево сборки с
именованными цветными деталями. Нужна голая плата для MCAD? Подними `--min-priority`
настолько, чтобы отсеялись все компоненты.

## Типичные проблемы

**Плата однотонная (нет текстур, GLB)**
Текстуры не экспортированы из Eagle. Запускай через `export3D.ulp` (а не `eagle2gltf`
руками) или укажи `--textures` на папку текстур.

**Компонент отсутствует**
1. Есть ли файл модели с именем футпринта (в `components_dir` / `step_components_dir`)?
2. Не стоит ли у детали `priority3d = -1` и не задан ли `Min Priority3d` выше её приоритета?

**9-плата не открывается в поставляемом Eagle 7 (managed-библиотеки)**
Платы с *managed*-библиотеками Eagle 9 могут не открыться в поставляемом Eagle 7
(задвоенные имена библиотек). Рекомендуется отвязать managed-библиотеки в Eagle 9 и пересохранить проект. Это можно сделать в полуавтоматическом режиме через экспорт используемых в пректе библиотек. 

**STEP-файл большой / медленно открывается**
Это природа точной B-rep сборки с множеством подробных деталей — нормально для любого
MCAD. Стоит использовать `Min Priority3d` (или `priority3d = -1`), чтобы включить только нужные
компоненты.
