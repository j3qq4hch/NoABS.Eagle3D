# Диалог: реалистичный рендер PCB в EAGLE через ULP

## Тема
Как получить реалистичное изображение печатной платы прямо в редакторе EAGLE,
с правильными цветами меди, паяльной маски, шелкографии и текстолита.

---

## Ключевые выводы

### Что можно делать в ULP
- **Читать** свойства слоёв: `LAYER.color`, `LAYER.name`, `LAYER.number`, `LAYER.visible`
- **Менять цвета** слоёв — только через генерацию команд (`exit(cmd)`), не напрямую
- **Читать объекты** на слоях: `wires`, `texts`, `circles`, `rectangles`, `polygons`
- **Копировать объекты** между слоями — через генерацию команд `WIRE`, `TEXT`, `CIRCLE`, `RECT`, `POLYGON`

### Палитра EAGLE
- Палитра меняется командой `SET PALETTE <index> <R> <G> <B>;`
- Индексы 0–15 — стандартные, лучше использовать 16–31 для своих цветов
- Сбросить: `SET PALETTE DEFAULT;`
- Фон: `SET BACKGROUND_COLOR <index>;`
- Назначить цвет слою: `LAYER <color_index> <fill> <number> <name>;`

## Проблема паяльной маски

В EAGLE слой `tStop`/`bStop` — **позитивный** (показывает где маски **нет**).
EAGLE рисует слои **аддитивно** — вычитать один слой из другого он не умеет.

### Решение: использовать порядок отрисовки EAGLE

EAGLE рисует слои снизу вверх. Это можно использовать в свою пользу:

```
Фон (background)  = цвет паяльной маски
Top/Bottom (медь) = медь под маской (чуть другой оттенок → трассы видны!)
tStop/bStop       = цвет финишного покрытия (ENIG/HASL) — рисуется ПОВЕРХ меди
tPlace/bPlace     = шелкография
Dimension         = цвет FR4 (виден только по краю платы)
```

Физический стек реальной платы и порядок отрисовки EAGLE **совпадают** —
tStop автоматически перекрывает медь в нужных местах, имитируя вырезы в маске.

## Готовый ULP: `pcb_realistic.ulp`

Запуск: `RUN pcb_realistic.ulp` из Board Editor.

Показывает диалог с полями RGB для каждого элемента платы:
- Паяльная маска (фон)
- Медь под маской
- Открытые пады (ENIG/HASL)
- Шелкография
- Текстолит FR4

### Задействованные индексы палитры

| Индекс | Назначение       | Слои EAGLE              |
|--------|-----------------|-------------------------|
| 16     | Паяльная маска  | background              |
| 17     | Медь            | 1 Top, 16 Bottom, 17 Pads, 18 Vias |
| 18     | Открытые пады   | 29 tStop, 30 bStop      |
| 19     | Шелкография     | 21 tPlace, 22 bPlace, 25 tNames, 26 bNames |
| 20     | FR4 / текстолит | 20 Dimension            |

### Команды EAGLE, используемые в ULP

```
SET PALETTE <index> <R> <G> <B>;   // задать цвет в палитре
SET BACKGROUND_COLOR <index>;      // цвет фона
LAYER <color> <fill> <num> <name>; // назначить цвет слою
DISPLAY NONE;                      // скрыть все слои
DISPLAY 1 16 17 ...;               // показать нужные
```

## Альтернатива: экспорт + Python

Если нужен фотореалистичный результат с полупрозрачной маской:

1. Экспортировать монохромные PNG каждого слоя из EAGLE:
   ```
   EXPORT IMAGE top_copper.png MONOCHROME 600 1;
   EXPORT IMAGE top_stop.png MONOCHROME 600 29;
   EXPORT IMAGE silkscreen.png MONOCHROME 600 21;
   EXPORT IMAGE outline.png MONOCHROME 600 20;
   ```

2. Наложить через Python (PIL/numpy):
   - Текстолит → медь под маской → маска (полупрозрачно, alpha ~0.8) → открытые пады → шелкография

**Минус**: при больших платах и высоком DPI — медленно.
**Плюс**: точная полупрозрачность маски, любой RGB.
