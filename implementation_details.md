# Общие соображения

Autodesk Fusion360 слишком медленный, его невозможно использовать. 
Все существующие утилиты для экспорта 3D-моделей из Eagle тоже работают не слишком хорошо или требуют ручных операций. Необходимо это исправить. 
Решение должно обладать вот такими свойствами:

1) Быть локальным.
2) Очень быстро работать.
3) Использовать только оригинальные *.brd файлы Eagle.
4) Иметь возможность экспортировать *.step файл.
5) Иметь возможность настройки внешнего вида печатной платы (эти данные также можно взять из brd файла).
6) Поддерживать текстуры и уметь их экспортировать.

Файл печатной платы Eagle(*.brd файл) содержит в себе всю необходимую информацию: описание контура платы и координаты всех компонентов.
Вот так выглядит описание контура платы в форме квадрата со стороной 10 мм

```html
<plain>
<wire x1="0" y1="0" x2="0" y2="10" width="0.01" layer="20"/>
<wire x1="0" y1="10" x2="10" y2="10" width="0.01" layer="20"/>
<wire x1="10" y1="10" x2="10" y2="0" width="0.01" layer="20"/>
<wire x1="10" y1="0" x2="0" y2="0" width="0.01" layer="20"/>
</plain>
```

По этом данным вполне возможно воспроизвести геометрию печатной платы.
Растровые изображения нужных комбинаций слоев можно получить средствами самого eagle при помощи скрипта texture_export.scr в этом репозитории.

# Детали реализации

## Воссоздание геометрии печатной платы

### Контур платы

В секции <plain> .brd файла содержится вся информация о неэлектрических сущностях платы. Здесь нужно найти описания всех линий (тег <wire>) на слое 20 и слое 46, они определяют контур печатной платы, толщины линий нужно игнорировать. Важно отметить, что печатная плата может содержать вырезы, т.е. любая плата может быть представлена как один самый большой внешний замкнутый контур, внутри которого может находиться несколько контуров-вырезов. 

### Монтажные отверстия и отверстия для выводных компонентов

Нужно найти описания всех отверстий (тег <hole>) и вырезать их из контура печатной платы.
Нужно найти описания всех компонентов, чьи футпринты имеют в своем составе пады для выводного монтажа (тег <pad> внутри тега <package>). Нужно вычислить координаты всех падов на печатной плате и вырезать их отверстия.

### Толщина печатной платы

Для вычисления толщины печатной платы нужно найти параметры layerSetup, mtCopper, mtIsolate (в тегах param)
mtCopper представляет из себя массив толщин всех слоев меди от 1 до 16. 
mtIsolate - массив толщин текстолита между медными слоями в порядке следования, т.е. первый элемент - толщина между слоем меди 1 и следующим за ним, второй элемент - толщина между слоем 2 и следующим за ним. Это необязательно будет слой 3, т.к. номера слоев не обязаны следовать по порядку, и 4-слойная печатная плата может описываться, например, так:  (1+2*15+16), т.е. за слоем 1 идет слой 2, потом слой 15, затем 16. Значит, нужно взять  первый, второй и пятнадцатый элементы массива mtIsolate
layerSetup содержит в себе выражение, описывающее стек печатной платы. 
Для получения толщины печатной платы нужно:

1) Найти все числа в layerSetup. Эти числа - индексы массива mtCopper. Нужно суммировать значения массива mtCopper по этим индексам 
2) Найти количестов математических знаков в выражении layerSetup(пусть это будет N). Суммировать первые N элементов массива mtIsolate.
3) Сложить результат из пункта 1 и пункта 2 

Например:

```html
<param name="layerSetup" value="(1+2*15+16)"/>
<param name="mtCopper" value="0.07mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.035mm 0.07mm"/>
<param name="mtIsolate" value="0.2mm 1mm 0.32mm 0.15mm 0.2mm 0.15mm 0.2mm 0.15mm 0.2mm 0.15mm 0.2mm 0.15mm 0.2mm 0.15mm 0.2mm"/>
```

Общая толщина медных слоев =  0.07mm + 0.035mm + 0.035mm + 0.07mm = 0.21mm
Общая толщина не медных слоев = 0.2mm + 1mm + 0.2mm = 1.4mm 
Общая толщина платы = 1.61mm

Дополнительное пояснение от Claude:
```
Алгоритм нахождения толщины печатной платы

Извлечь все числа из выражения layerSetup — это список индексов медных слоёв в порядке их следования в стеке. Например, (1+2*15+16) → [1, 2, 15, 16]
Сумма меди: взять значения из массива mtCopper по этим индексам и сложить их все.
Сумма диэлектрика: взять тот же список индексов, отбросить последний, и по оставшимся индексам взять значения из массива mtIsolate и сложить их. Логика в том, что между N медными слоями есть N−1 диэлектрических прослоек, и индекс прослойки соответствует индексу медного слоя, после которого она идёт.
Итог: сложить сумму меди и сумму диэлектрика.
```

## Воссоздание рисунка печатной платы

### Обработка текстур

У каждой печатной платы есть две стороны: верхняя(top) и нижняя(bottom).

При помощи скрипта texture_export.scr из eagle экспоритруется набор черно-белых изображений платы:

* outline.png - содержит контур печатной платы и может быть использован для обрезки остальных текстур и совмещения. 
* top_copper.png - верхний слой меди  
* top_mask.png - верхний слой паяльной маски, в нем содержатся вырезы в паяльной маске
* top_silk.png - верхний слой шелкографии 
* bottom_copper.png - верхний слой меди  
* bottom_mask.png - верхний слой паяльной маски, в нем содержатся вырезы в паяльной маске
* bottom_silk.png - верхний слой шелкографии 
* ref1.png - содержит первую референсную точку
* ref2.png - содержит вторую референсную точку

Все эти файлы хранятся в директории textures, которая находится рядом с файлом .brd
Информация о цветах печатной платы хранится в brd файле в тегах <mfgpreviewcolor>.
soldermaskcolor - цвет паяльной маски
silkscreencolor - цвет шелкографии
coppercolor - цвет меди
substratecolor - цвет подложки 

Значение color для всех цветов 32-битное число, записанное в 16-ричном виде

Байт 1 - значение синего цвета
Байт 2 - значение зеленого цвета
Байт 3 - значение красного цвета
Байт 4 - значение альфа-канала (прозрачность)

name="soldermaskcolor" color="0xC8 00 80 00"/>
<mfgpreviewcolor name="silkscreencolor" color="0xFF FEFEFE"/>
<mfgpreviewcolor name="backgroundcolor" color="0xFF 282828"/>
<mfgpreviewcolor name="coppercolor" color="0xFF FF BF 00"/>
<mfgpreviewcolor name="substratecolor" color="0xFF 78 6E 46"/>
Во всех текстурах есть черный фон, который нужно удалить. Далее следует сделать следующее:

1) В файле pads.png находится набор белых областей, внутри каждой из которой есть черная. Это отверстия 
Нужно удалить из этого файла все, кроме этих внутренних черных областей. Эти черные области нужно перенести в файл outline.png.
2) В файле outline.png находится внешний контур платы, внутри которого могут быть другие замкнутые контуры - вырезы в плате, а также черные залитые черные области - отверстия в плате. Все внутренние области нужно залить черным. Затем внешний контур залить белым. Эта белая область дальше будет использоваться как маска для наложения на другие файлы.  
3) Использовать получившееся в пункте 1 изображение как маску для всех остальных файлов: оставить в них только то, что перекрывается с белой областью.
4) В файле top_copper.png Сделать цвет всех белых пикселей coppercolor 
5) В файле top_copper.png Сделать цвет всех белых пикселей coppercolor 
6) В файле top_silk.png удалить все, что перекрывается с белыми областями из файла top_mask.png (т.е использовать top_mask.png как маску для top_silk.png). Изменить цвет всех белых пикселей на silkscreencolor.  
7) В файле bottom_silk.png удалить все, что перекрывается с белыми областями из файла bottom_mask.png (т.е использовать bottom_mask.png как маску для bottom_silk.png). Изменить цвет всех белых пикселей на silkscreencolor.  
8) В файле top_mask.png вырезать все белые области (они должны стать прозрачными). Все остальное залить цветом soldermaskcolor, альфа-канал также взять из soldermaskcolor.
9) В файле bottom_mask.png вырезать все белые области (они должны стать прозрачными). Все остальное залить цветом soldermaskcolor, альфа-канал также взять из soldermaskcolor.
10) Создать текстуру верхнего слоя печатной платы, объединив слои outline.png + top_copper.png + top_mask.png + top_silk.png (именно в таком порядке, т.е top_silk должен оказаться на самом верху). Записать итоговый файл в texture_top.png
11) Создать текстуру нижнего слоя печатной платы, объединив слои outline.png + bottom_copper.png + bottom_mask.png + bottom_silk.png (именно в таком порядке, т.е bottom_silk должен оказаться на самом верху).  Записать итоговый файл в texture_bottom.png

### Совмещение текстур

DPI у всех файлов текстур одинаковый, его можно взять из метаданных самих PNG файлов. 

## Сопоставление библиотеки

Чтобы добавить на 3D-модель платы 3D-модели комопнентов, необходимо как-то сопоставить футпринт с конкретной моделью. И не только это, но еще и корректно сориентировать модель на футпринте. 
Важные обстоятельства: 
1) Нужно избежать любой внешней системы учета, не нужно создавать библиотеку более высокого порядка
2) Все модели хранятся локально в виде отдельных степ-файлов в одной директории
3) Библиотека, поддерживающая 3D-модели, должна оставаться обычной локальной (не managed) eagle-библиотекой, которую можно использовать и без 3D.

Сопоставить step файлы с футпринтами можно просто по имени. Необходимо, чтобы имя футпринта в библиотеке совпадало с именем step-файла. 
Данные для корректной ориентации модели компонента - это 6 чисел: 3 числа трансляции по трем осям и 3 числа поворота по трем углам. Они могут храниться в описании (description) футпринта в самой библиотеке. Также там может храниться ссылка на чертеж футпринта от производителя и ссылка на источник модели.

Для связывания библиотеки с моделями потребуется интерактивная утилита, которая на входе получает файл библиотеки орла (lbr файл). Интерфейс утилиты минималистичен: в левой части экрана располагается список футпринтов (1 футпринт на 1 строку), в правой - окно 3д просмотра с ортогональной проекцией. Снизу в левой части экрана должна быть кнопка "Open library", в правой части экрана - кнопка "Apply". При загрузке библиотеки утилита находит все футпринты из этой библиотеки. Далее утилита ищет соответствующие модели в папке step. Утилита отображает список футпринтов в левой части экрана, футпринты, для которых не оказалось подходящего файла модели должны быть подсвечены красным. Футпринты, для которых модели нашлись, но пока нет никаких данных об ориентации модели, должны подсвечиваться желтым.
Все футпринты, кроме красных, должны быть кликабельны. При нажатии на футпринт в окне 3D просмотра должна отобразиться поверхность печатной платы, на которой будет сам футпринт (только геометрия со слоев top(1), tplace(21), pads(18)) и соответствующая 3D модель. На 3D модели должны быть органы для ручного перемещения модели в окне просмотра (нужна возможность перемещать модель руками). Лучше скопировать органы перемещения модели из окна привязки 3д модели в Autodesk eagle. Также нужны 6 тектовых полей для ручного ввода данных ориентации компонента. При перемещении модели мышкой данные в этих полях также должны обновляться. А при нажатии enter после ввода в любое из этих полей модель должна перемещаться так, как указывают эти поля.
При нажатии кнопки ПРИМЕНИТЬ данные об ориентации компонента должны записываться в библиотеку(lbr-файл), а 3D модель компонента должна дополнительно конвертироваться в формат glb и сохраняться в директорию /step/tesselated. Это потребуется для ускорения загрузки финальной модели платы с компонентами позднее.

Корректная тесселяция step-файлов с сохранением взаимного расположения компонентов в составных файлах и данных о материалах (цветах) компонентов оказалась крайне нетривиальной задачей. Единственным работающим вариантом оказалось использование утилиты drawexe из пакета Open CASCADE Technology. Для этого нужно скачать [opencascade-7.9.3-vc14-64-combined.zip](https://github.com/Open-Cascade-SAS/OCCT/releases/download/V7_9_3/opencascade-7.9.3-vc14-64-combined.zip) и затем воспользоваться скриптом step2glb.py для ручной конвертации. Этот же способ использует и утилита glue. Существует наглядный интерактивный сборник примеров для утилиты drawexe, он доступен [по ссылке](https://draw.sview.ru/xde-export-step2gltf/).
